# 🚀 YouTube Channel Name Generator PRO - Python

A professional and advanced Python tool to generate creative, unique, and professional YouTube channel names. Perfect for new content creators.

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![License](https://img.shields.io/badge/License-MIT-green)
![Status](https://img.shields.io/badge/Status-Active-success)

### ✨ Features

- **OOP Architecture:** Built with clean Class-based structure
- **15+ Unique Ideas:** Generates 15 professional names in one run, not just one
- **3 Different Styles:**
    - `PRO` - For professional & official channels
    - `FUN` - For gaming & entertainment channels
    - `SHORT` - For modern & short names
- **Auto-Save:** Automatically saves all generated names to a `.txt` file
- **Smart Formatting:** Auto-corrects user input (capitalization & spaces)
